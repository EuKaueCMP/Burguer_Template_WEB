# Burguer Template WEB

Responsive landing page and interactive digital menu template for artisanal burger restaurants.

## Description

Burguer Template WEB is a front-end website template designed for burger shops and casual dining venues. It provides a modern customer-facing storefront featuring brand identity presentation, dynamic category-based menu browsing, and a product details modal with automated WhatsApp ordering links.

## Technologies

- **Markup:** HTML5
- **Styling:** CSS3 (Flexbox, Grid, CSS Variables)
- **Scripting:** Vanilla JavaScript (ES6+)
- **Typography & Icons:** Google Fonts (Inter, Oswald), Google Material Symbols

## Features

- **Hero & Branding:** Header with active store indicator ("Chapa Aberta") and navigation links.
- **Interactive Menu Tabs:** Tabbed navigation to filter items by product category.
- **Product Detail Modal:** Detailed view showing product images, descriptions, and pricing.
- **WhatsApp Direct Order:** One-click integration that generates pre-formatted WhatsApp order messages.
- **Keyboard & Click Accessibility:** Modal dismissal via `Escape` key and backdrop clicking.
- **Responsive Layout:** Optimized display across desktop, tablet, and mobile screens.

## Setup & Usage

### Prerequisites
- Any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari)

### Running Locally
1. Clone the repository:
```bash
git clone https://github.com/EuKaueCMP/Burguer_Template_WEB.git
```

2. Open the project folder:
```bash
cd Burguer_Template_WEB
```

3. Open `index.html` directly in your browser, or serve it using an extension such as VS Code Live Server:
```bash
# If using Python simple HTTP server:
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000`.
